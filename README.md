# Emotion Detector

## Project Description

Emotion Detector is a Python-based web application that analyzes text and identifies the dominant emotion expressed in the input.

The application provides a simple web interface using Flask. Users can enter a sentence and receive an emotion detection result.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Unit Testing
- Pylint

## Emotions Detected

The application identifies the following emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness
